# Help Empower Refugees (HER) website

Static HTML, CSS and vanilla JavaScript website prototype for Help Empower Refugees (HER). Open `index.html` in a browser or serve the folder with any static server.

## Content status

The site deliberately labels placeholder images, stories, funding targets, partner information and statistics as demo content. Replace these with confirmed information and approved HER photographs before publication. The contact form validates input in the browser only; it needs a backend or email service before it can send messages.

## Structure

- `css/` holds shared, responsive and motion styles.
- `js/` holds small reusable modules for navigation, counters, filtering, gallery and form validation.
- Pages use semantic HTML and can be deployed to GitHub Pages or another static host.
